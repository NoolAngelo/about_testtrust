Why TestTrust?

More trust. Less intrusion.

Tools that help educators review online exam activity without relying on camera-based monitoring.

Privacy-focused

No camera, microphone, or biometric data. TestTrust focuses on supported browser events.

Real-time monitoring

Suspicious browser activity can be sent to the proctor dashboard for review.

Proctor dashboard

Review event details and risk indicators in one place to support exam supervision.

Simple workflow

How it works

Three parts work together to help proctors review browser activity during an online exam.

1

Student takes the exam

The TestTrust extension runs in the student's supported Chromium browser and monitors configured browser events.

→
2

Events are stored

Session activity is sent to the Firebase cloud backend for storage and dashboard use.

→
3

Proctor reviews activity

The dashboard helps proctors review events and risk indicators. A flag is a signal to review, not proof of cheating.
